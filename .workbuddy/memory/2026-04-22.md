## 第十三轮修复（09:53）

**用户反馈3个问题**：

### 1. 个人积分取值改为按个人名字（不按部门合计）
- **问题**：个人榜右侧柱状图（DepartmentChart）按部门聚合UserScore，显示的是各部门个人积分合计
- **修复**：后端 `department_data` 在 `orgType=="user"` 时改为按 User.id/name 聚合，limit 10，返回个人名字和积分
- **结果**：个人榜右侧柱状图显示 `👤 个人积分 Top10`，纵轴为人名而非部门名

### 2. 部门积分左侧列表缺少0分部门
- **问题**：部门榜左侧排行榜只显示15个部门（有积分的），缺少4个0分部门(id=8,16,18,19)
- **根因**：后端 outerjoin(TeamScore) + filter(TeamScore.score_date >= start_date) → filter作用在outerjoin右侧 → 等效INNER JOIN → 无TeamScore记录的部门被过滤掉
- **修复**：改为子查询(subquery)方式 — 先在子查询中按department_id聚合TeamScore（带日期/渠道过滤），再 LEFT JOIN 到 Department 表 — 确保所有19个部门都出现，0分部门score=0
- **影响范围**：ranking查询 + department柱状图查询都改了

### 3. 部门积分季榜计算空白
- **问题**：前端切到季榜后数据为空
- **根因**：store.quarter 初始值为 `null` → 前端 Select 显示 `quarter||1=1`（Q1）但实际不传quarter参数 → 后端 quarter=None → `_period_to_date_range` 用当前月份(4月)算出Q2 → 查4-6月无数据
- **修复**：store.quarter 初始值从 `null` 改为 `1` — 切季榜时自动传quarter=1给后端
- **验证**：Q1部门榜返回19个部门（15个有分+4个0分）
