**关键 bug 说明**：
- 参考代码 `def get_ranking(db=next(get_db()))` 是反模式：`next(get_db())` 在模块加载时执行一次，同一个 db session 被所有请求复用，会导致事务污染和连接泄漏
- 正确写法：`db: Session = Depends(get_db)`，每次请求新建 session

### 1. 首页默认进入部门榜年榜
- **原默认值**：`timeType="month"`, `orgType="user"` — 进入后显示个人榜月榜
- **修复**：store初始值改为 `timeType="year"`, `orgType="department"` — 默认进入部门榜年榜

### 2. 明细弹窗关闭动画
- **问题**：点开明细动画OK，但关闭时没有反向动画（直接消失）
- **根因**：antd5的CSS动画类名（ant-modal-leave / ant-motion-leave）可能与实际DOM不匹配，导致关闭动画CSS规则未命中
- **修复方案**：
  - JS层面：DetailModal用 `modalOpen` 状态控制，关闭时先 `setModalOpen(false)` 触发antd内置退出动画，再用 `setTimeout(320ms)` 延迟清理数据
  - CSS层面：同时支持 `ant-motion-*` 和 `ant-modal-*` 两套类名，覆盖不同antd版本
  - 关闭动画：`translateY(0) scale(1) → translateY(30px) scale(0.97) + opacity 1→0`，300ms `cubic-bezier(0.4, 0, 1, 1)` 加速淡出
  - 遮罩同步：300ms淡出

## 第八轮修复（16:20）

**用户反馈3个问题**：

### 1. 部门积分柱状图需显示全部部门+增大高度
- **修复**：后端 limit(20) 改为 .all()（返回全部部门）
- **修复**：前端柱状图改为全宽 `<Col xs={24}>`，动态高度 `Math.max(300, deptCount * 28 + 70)`
- **修复**：日历热力图也改为全宽 + 增高到 300px，cellSize 15
- **修复**：趋势图和饼图也增高到 300px

### 2. 点击员工榜员工名会触发筛选（左侧排行不应该变）
- **根因**：点击排行行设置 selectedId → 触发 statsApi 重新请求 → 在 orgType=user 且 selectedId 是部门ID 时，后端排行查询 `filter(User.department_id == selectedId)` 导致排行被部门过滤
- **修复**：selectedId 只用于右侧图表联动，排行榜数据源始终不受 selectedId 过滤
- 后端 ranking 查询：selectedId 只在 orgType=department 时作为部门筛选，orgType=user 时不做 selectedId 过滤（排行榜始终显示全部员工）

### 3. 明细弹窗白底毛玻璃 + 关闭反向动画
- **修复**：GLASS_MODAL_PROPS background 改为 `rgba(255,255,255,0.96)` 白底
- **修复**：CSS 关闭动画添加 `cubic-bezier(0.4, 0, 1, 1)` 缓动（与打开反向）
- **修复**：遮罩层添加 mask-leave 动画同步淡出
